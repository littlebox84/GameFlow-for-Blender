# GameFlow Roadmap

## Public alpha

- Stabilize WASD/QE movement and RMB mouse-look.
- Preserve ordinary Blender selection, gizmos, menus, editors, and workspaces.
- Keep mouse-wheel zoom reliable.
- Recover cleanly after opening or creating Blender projects.
- Back up and restore affected Blender keymap states.
- Provide beginner-friendly presets plus an Advanced section.
- Document Steam Input controller support.

## Beta

- Improve first-run onboarding.
- Add clearer visual status for active/paused navigation.
- Test Blender 4.2, 4.3, 4.4, 5.x and future versions.
- Expand controller/Steam Deck testing.
- Add import/export of GameFlow profiles.
- Add optional control hints that disappear once learned.
- Improve accessibility presets and configurable acceleration/deceleration.

## 1.0 goals

- One-click installation and setup.
- Safe automatic keymap backup and restoration.
- Reliable project/workspace lifecycle handling.
- Intuitive defaults requiring no manual for basic navigation.
- Polished controller workflow.
- Public open-source license selected.
- Automated packaging and basic CI validation.

## Guiding principle

**GameFlow should teach creation, not navigation.**
