# Contributing to GameFlow

Thanks for helping make Blender easier to enter.

GameFlow is especially interested in contributions involving:

- Blender-version compatibility testing;
- Windows, Linux, and macOS testing;
- Xbox, PlayStation, Steam Deck, and Steam Input testing;
- navigation bugs;
- keymap conflicts;
- accessibility improvements;
- beginner UX and onboarding;
- documentation.

## Before opening a bug

Please include:

- Blender version;
- operating system;
- GameFlow version;
- whether GameFlow Minimal, Conflicts Only, or Native keymap mode was active;
- exact steps to reproduce the issue;
- any traceback Blender displayed.

## Pull requests

Keep changes focused and explain the user-facing reason for them. GameFlow's core principle is that basic navigation should be intuitive without requiring users to understand Blender's keymap system.

When changing input behavior, test ordinary Blender interaction as well: selection, gizmos, menus, Outliner, Properties, workspace switching, and file loading.

## Product principle

**GameFlow should teach creation, not navigation.**
